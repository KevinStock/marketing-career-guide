ターゲティングマーケティングとは、適切な人に適切なメッセージを届け、データを使って成果を高めていく仕事です。日本の広告の中で最も伸びている分野で、毎年多くの企業が未経験者を採用しています。この8つのガイドでは、未経験から約6か月で最初のマーケティングの仕事に就くまでの道のりを紹介します。

## なぜ今なのか

2025年、インターネット広告費が初めて日本の総広告費の半分を超えました。特に伸びているソーシャル広告と動画広告は、まさにターゲティングマーケティングのスキルが使われる分野です。

| 区分（電通、2025年） | 広告費 | 前年比 |
| --- | --- | --- |
| 総広告費 | 約8兆600億円 | +5.1% |
| インターネット広告費 | 約4兆500億円（総広告費の50.2%） | +10.8% |
| ソーシャル広告 | 約1兆3,100億円 | +18.7% |
| 動画広告 | 約1兆300億円 | +21.8% |
| テレビ・新聞・雑誌・ラジオの合計 | 約2兆3,000億円 | −1.6% |

2026年のインターネット広告媒体費は、動画とソーシャルを中心にさらに8.3%伸びると予測されています（[電通](https://kyodonewsprwire.jp/release/202603045005)、[CARTA・電通・セプテーニ](https://kyodonewsprwire.jp/release/202603034899)）。

**つまり：** 仕事が増えているのは、SNSや動画の運用型広告です。Instagram、TikTok、YouTube、LINEのスキルは、一般的なマーケティング理論よりも企業に評価されます。

## 日本で知っておきたいプラットフォーム

日本のプラットフォーム事情は海外と異なります。GoogleとInstagramのほかに、次のものを押さえておきましょう。

- **LINE** — LINE公式アカウントとLINEヤフー広告で、多くの人が毎日使うメッセージアプリの中にいるユーザーに届けられます。
- **Yahoo! JAPAN** — 検索広告やディスプレイ広告は今もGoogleと並んで使われており、求人票でもYahoo!広告のスキルが求められます。
- **X（旧Twitter）** — 日本では、多くの国よりもはるかに重要な存在です。
- **TVerとコネクテッドTV** — 急成長している動画広告の一部で、経験者向けの求人要件にもすでに登場しています。

## 日本のマーケターが必ず知っておくべき3つのルール

| ルール | 実務での意味 |
| --- | --- |
| ステマ規制（2023年10月1日施行） | 景品表示法により、広告であることを隠して一般の感想のように見せる表示は違法です。PR投稿には「#PR」や「【広告】」などのわかりやすい表示が必要で、責任を負うのは広告主です。初めての措置命令（2024年6月）は、割引と引き換えに書かせたGoogleマップの口コミに関するものでした（[ISSOH](https://www.issoh.co.jp/column/details/4794/)）。 |
| 外部送信規律（2023年6月施行） | 改正電気通信事業法により、多くのサイトは、Cookieや広告IDなどの利用者情報を第三者に送信していることを公表する必要があります（[創業手帳](https://sogyotecho.jp/cookie-impact/)）。 |
| 個人関連情報（2022年4月施行） | 改正個人情報保護法により、Cookieなどのデータを、それを個人と結びつける会社に渡すことが制限されています（[Web担](https://webtan.impress.co.jp/e/2023/05/19/44501)）。 |

面接でステマ規制を説明できれば、多くの応募者よりも経験があるように見られます。

## よく出てくる用語

| 用語 | 意味 |
| --- | --- |
| 運用型広告 | 検索広告やSNS広告など、日々調整しながら運用する広告 |
| リスティング広告 | GoogleやYahoo!の検索結果に表示される広告 |
| インプレッション（imp） | 広告が表示された回数 |
| CTR（クリック率） | クリック数 ÷ 表示回数 |
| CVR（コンバージョン率） | 購入・登録数 ÷ クリック数 |
| CPA（顧客獲得単価） | 広告費 ÷ 購入・登録数 |
| ROAS（広告費用対効果） | 広告経由の売上 ÷ 広告費 |
| KPI | チームが追いかけると決めた主要な数字 |
| LP（ランディングページ） | 広告をクリックした人が最初に見るページ |
| ペルソナ | ターゲットとなる顧客の具体的な人物像 |
