「未経験歓迎」や「未経験OK」の求人を探し、転職エージェントに1社以上登録しましょう。日本の転職エージェントは求職者は無料で使え、職務経歴書づくりも手伝ってくれることが多いです。

## 探す場所

| 探し方 | 向いていること |
| --- | --- |
| doda、マイナビ転職、エン転職 | 未経験OKの広告運用の求人を含め、求人が多い（[dodaの求人例](https://careerconnection.jp/job/A0223015205769-detail)、[エン転職のマーケティング求人](https://employment.en-japan.com/k_113300/s_marketing/)） |
| リクルートエージェント、マイナビエージェント | 異業種からの転職のサポート、書類の添削、面接の練習 |
| リクルートダイレクトスカウト | 企業から直接連絡が来る。見せられる成果ができてから役立つ |
| [JACリクルートメント](https://www.jac-recruitment.jp/market/it/web-marketing/) | ミドル層やバイリンガル向けの求人。多くは非公開求人 |
| 広告代理店の採用ページ | 未経験者を最も採用しているのは代理店なので、各社のサイトも確認する |

## 採用担当者が見ていること

日本の人材紹介会社は、どの作品も「施策・仮説・改善・結果・再現性」の5つで説明するようすすめています（[Remedy](https://remedy-tokyo.co.jp/media/10948/)）。作品のまとめ方はガイド6を見てください。面接には、5〜10ページのポートフォリオを毎回持っていきましょう（[リクルートエージェント](https://www.r-agent.com/guide/start/12572/)）。

## 職務経歴書

- これまでの仕事を、マーケティングの言葉で説明します（例はガイド2）。営業、カスタマーサポート、EC、ライティング、Web制作の経験は、どれも生かせます。
- 資格は、取得した年月とともに書きます。
- 実際のキャンペーンや副業の成果を、数字とともに書きます。
- 応募の前に、エージェントに添削してもらいましょう。

## 面接の練習

面接では、キャンペーンについて説明を求められることがよくあります。自分の作品について、次の質問に声に出して答える練習をしましょう。良い答えは短く、数字を使い、理由を述べています。

1. この広告は、具体的に誰に向けたものですか？その人物像を説明してください。
2. このキャンペーンの目標は何で、達成できましたか？
3. 顧客1人あたりのコスト（CPA）はいくらで、このビジネスにとって良い数字ですか？
4. 明日予算が半分になったら、まず何を止めますか？その理由は？
5. 次に何をテストしますか？どんな結果が出たら考えを変えますか？
6. このPR投稿は、ステマ規制に沿って正しく表示されていますか？（ガイド1）

## タイミング

ポートフォリオに実際のキャンペーンが1つ入ったら、応募を始めましょう。3つそろうのを待つ必要はありません。30歳以上なら、「もう1つ講座を終えてから」と待たずに、もっと早く始めましょう（[マイナビエージェント](https://mynavi-agent.jp/knowledge/it/1278.html)）。
